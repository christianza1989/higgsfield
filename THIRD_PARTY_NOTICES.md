# Prompt collection

`lib/data/prompts.json` imports text and attribution from
[EvoLinkAI/awesome-seedance-2.5-prompts](https://github.com/EvoLinkAI/awesome-seedance-2.5-prompts),
commit `8d742ba749e9d08ddb29030b03568558bc5d2d0f`.

The repository's LICENSE file contains Apache License 2.0, copyright 2024
EvoLinkAI. A copy is preserved at `licenses/EvoLinkAI-LICENSE.txt`. The upstream
README also contains a CC BY 4.0 badge and an outdated statement that a final
license file has not been added. This notice preserves that discrepancy.

The curated entries credit their original authors and link to the original
posts. These credits and links remain part of the imported data and interface.
Third-party example videos and images are not downloaded to the project or
redistributed. The app streams upstream video URLs in a browser player, or
uses X's official embedded tweet widget when no direct video URL is provided.
The import adds stable IDs, categories, reference hints, and collection metadata.
